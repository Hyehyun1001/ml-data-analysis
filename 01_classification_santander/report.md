# santander_customer_satisfaction 에 관한 프로젝트
- 이 프로젝트는 santander_customer_satisfaction에 관한 프로젝트로 해당 데이터 셋을 이해하고 분석의 전 과정을 직접 설계 및 수행하는 것을 목표로 한다.

## 각 절차 및 수행 과업
01. 데이터 이해 및 EDA
02. 데이터 전처리
03. 모델링 및 비교
04. 하이퍼파라미터 회적화
05. 성능평가 및 해석
06. 결론 및 회고 작성

## 분석 보고서 작성 순서
1. 서론
2. 데이터 소개
3. 데이터 전처리
4. 모델링
5. 결과
6. 결론
7. 회교

### 데이터 소개
- 변수의 규모를 describe나 info를 활용해서 통계적인 수치를 표로 넣도록 한다.
- 이때 가능한 특성과 구조를 시각화하여 어떤 데이터들이 있는지를 이해하도록 한다.

### 데이터 전처리
- 데이터 전처리를 정리할 때 각 저장된 이미지를 활용한다.
- 이상치, 결측치, 파생 변수를 생성하는 등 각 기법을 적용하도록 한다.

### 모델링
#### 모델링에서 사용된 모델의 순서
1. Decision Tree
2. GBM
3. XGB
4. LGBM
5. Randomforest
6. Logistic Regression

#### 모델링 성능비교
- 각 모델마다 나온 결과값을 정리하도록 한다. 기본적인 정리는 글로 작성하도록 한다.
- 같은 모델안에 나온 결과값을 표로 비교할 수 있도록 설명글 아래 전처리나 모델 파라미터의 변경점 그리고 그에 따른 정확도 및 평가점수 비교를 표로 만들어 한눈에 볼 수 있도록 한다.
- 하이퍼파라미터로 최적화를 했을 때 나오는 결과값과 그에 따른 베스트파라미터값을 기록하여 수동으로 파라미터를 조절하여 진행했을 때 결과값과 hyperOpt를 사용했을 때의 차이를 비교할 수 있도록 한다.

## 서브 에이전트 전략
- 본 보고서를 작성하는데 있어 각 서브에이전트를 사용하여 정확하고 빠르게 진행하는 것을 목표로 한다.
- 빠른 것보다는 정확한 것에 더 초점을 두도록 한다.

### 총괄 에이전트
- 총괄 에이전트는 각 에이전트에 명령을 내려 정확하게 해당 내용을 수행하는지의 여부와 검토 역할을 진행하도록 한다.
- 설명에 대한 부분과 차트나 그림에 대한 부분을 확인하여 충분한 보충설명이 되는지와 설명에 대한 부분이 명확한지 검토한다.
- 보고서의 순서가 위에 설명된 과업과 작성 순서대로 작업물이 나오는지 확인하도록 한다.

### 설명 에이전트
- 설명 에이전트는 각 문단 안에 문장이 매끄럽게 진행되도록 하며, 문단과 문단 내용이 이어질 수 있도록 작성하고 한번의 검토를 실행하며, 총괄 에이전트에도 한번 검토를 받도록 한다.
- 설명 에이전트는 한 문단의 내용이 끝나면 시각화 할 수 있는 부분들을 차트 에이전트에게 넘겨 그 부분을 근거 자료나 보충설명을 해줄 수 있는 그림이나 차트를 만들 수 있도록 전달한다.
- 검토 에이전트에도 전달하여 내용이 매끄럽게 이어지는지 전체적인 부분에 대해서 검토를 진행하도록 한다.

### 차트 에이전트
- 차트 에이전트는 각 코드 부분에서 시각화를 해볼 수 있는 부분들을 시각화하는 matplotlib를 활용하여 설명에이전트에게서 받은 부분들을 충분히 설명할 수 있게 차트로 만들어두도록 한다.
- 각 차트나 그림은 PNG파일로 저장하며, 어느 부분에 대한 차트인지 파일명으로 간단하게 표시하도록 한다.
- 한 챕터에 많은 그림이나 차트를 사용할 경우 순서대로 파일이 저장될 수 있게 파일명을 지정하도록 한다.
- 그림이나 표를 검토 에이전트에게도 전달하여 확인해볼 수 있도록 한다.

### 검토 에이전트
- 검토 에이전트는 설명 에이전트의 문단이 충분히 설명이 되는지 확인하도록 한다.
- 차트나 그림을 받아서 확인했을 때, 문단과 매끄럽지 않은 부분이 발견되면 다시 각 에이전트에 전달하여 수정할 수 있도록 한다.
- 이미지나 차트에서 깨진 부분이 있는지 확인하도록 한다.
