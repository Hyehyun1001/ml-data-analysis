## 5. 하이퍼파라미터 최적화 상세 분석

### 5.1 최적화 설정

| 항목 | 값 |
|------|-----|
| **탐색 알고리즘** | Tree-structured Parzen Estimator (TPE) |
| **탐색 반복 수** | 30회 |
| **CV 전략** | 3-Fold Stratified K-Fold |
| **목적함수** | 3-Fold CV 평균 ROC-AUC 최대화 |
| **조기 종료 조건** | n_iter_no_change=20, tol=1e-4 |

### 5.2 탐색 공간 및 최적값

#### 탐색 범위 → 최적값 비교

| 파라미터 | 탐색 범위 | **최적값** | 선택 위치 |
|---------|---------|-----------|---------|
| **n_estimators** | 100-400 | **350** | 상단 근처 (부트스트랩 분할 필요) |
| **learning_rate** | 0.02-0.10 | **0.0221** | 하단 근처 (느린 학습) |
| **max_depth** | 3-6 | **4** | 중간값 (적절한 복잡도) |
| **subsample** | 0.7-1.0 | **0.877** | 상단 (데이터 대부분 활용) |
| **max_features** | ['sqrt', 'log2', None] | **'sqrt'** | 피처 수 제곱근 (불안정성 감소) |
| **min_samples_split** | 2-10 | **6** | 중간값 (리프 노드 균형) |

**최적화 결과 평가:**

✅ **장점:**
- **Learning Rate 매우 낮음 (0.0221):** 과적합 위험 감소, 정규화 효과
- **높은 n_estimators (350):** 느린 학습률 보완, 부트스트랩 분할로 안정성 강화
- **적절한 max_depth (4):** 복잡도와 해석성 균형

⚠️ **주의점:**
- **subsample=0.877:** 거의 전체 데이터 사용 → 부트스트랩 분할 효과 감소 (가능한 과적합)
- **max_features='sqrt':** 피처 무작위 선택 → 다양성 확보 (긍정적)

### 5.3 하이퍼파라미터 해석

**발견된 패턴:**

```
높은 n_estimators + 낮은 learning_rate = 앙상블의 안정성 강조
적절한 max_depth + 높은 subsample = 주의 깊은 복잡도 제어
max_features='sqrt' = 피처 다양성과 계산 효율성의 균형
```

**의미:**
- 모델이 과적합을 피하면서 정확도를 높이는 **보수적 접근** 선택
- 소량의 여유 정규화(subsample>0.85)로도 충분할 것으로 판단

### 5.4 최적화 과정 메트릭

```
최적화 실행: 9분 37초 (30회 × 평균 19.25초)
최적값의 손실함수: -0.8411 (ROC-AUC ≈ 0.8411)
```

**평가:**
- ✅ **합리적인 수렴:** 30회로 안정적인 최적값 도달
- ✅ **탐색 효율:** TPE 알고리즘이 잘 작동

- ✅ **내재적 불균형 대응:** 가중치 조정으로 소수 클래스 중시

- ✅ **ROC-AUC 사용:** 불균형 데이터에 적절한 평가 지표

- ✅ **Excellent와의 격차:** ~7% (0.90 달성을 위한 추가 개선 필요)

## 11. 파이프라인 설계의 강점과 약점

### 11.1 강점 ✅

| 강점 | 상세 |
|------|------|
| **Data Leakage 차단** | Train 기준으로 Scaler/PCA 학습 후 Test 적용 |
| **체계적 전처리** | 이상치 → 파생변수 → 정제 → 피처선택 순서 정확 |
| **자동 하이퍼 최적화** | Hyperopt TPE로 수동 튜닝 제거, 객관적 결과 |
| **다중 검증 전략** | 3-Fold (최적화) → 5-Fold (평가) → 테스트 (최종) |
| **클래스 불균형 대응** | Stratified KFold로 모든 검증에서 비율 유지 |
| **고도의 안정성** | CV 표준편차 0.58%로 매우 안정적 재현성 |

### 11.2 약점 및 개선점 ⚠️

| 약점 | 개선 방법 |
|------|---------|
| **PCA 설명도 미제시** | `pca.explained_variance_ratio_.sum()` 확인 필요 |
| **임계값 고정** | Precision-Recall 곡선으로 비즈니스 맞춤 임계값 탐색 |
| **다중 분류 지표 부재** | Precision/Recall/F1-score/ROC curve 시각화 추가 |
| **SHAP/Feature Importance** | 모델 해석성 강화를 위해 상위 피처 분석 추가 |
| **앙상블 미활용** | 다양한 모델(XGBoost, LightGBM, RF)과 stacking 고려 |
| **Calibration 검증 없음** | Brier score, Calibration plot으로 확률 신뢰도 확인 |
