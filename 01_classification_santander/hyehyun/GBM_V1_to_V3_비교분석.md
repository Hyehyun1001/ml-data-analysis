### 1.2 V3 (개선)

```python
X_features['n0'] = (X_features == 0).sum(axis=1)          # 0의 개수
X_features['row_std'] = X_features.std(axis=1)            # 표준편차
X_features['row_mean'] = X_features.mean(axis=1)          # 평균
```
